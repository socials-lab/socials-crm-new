# ARES (Czech Business Registry)

Developer info: https://ares.gov.cz/stranky/vyvojar-info  
Swagger UI: https://ares.gov.cz/swagger-ui/

## Base URL

`https://ares.gov.cz/ekonomicke-subjekty-v-be/rest`

## Usage Limits

According to the developer info page, ARES may throttle or block clients that exceed:

- 500 requests per minute
- repeated invalid or duplicate queries
- excessive parallel automated queries
