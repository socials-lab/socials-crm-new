# OAuth 2.0 Scopes

Source: https://developers.google.com/workspace/calendar/api/auth

## Common Scopes

- `https://www.googleapis.com/auth/calendar`  
  Full access to all calendars.

- `https://www.googleapis.com/auth/calendar.readonly`  
  Read-only access to calendars.

- `https://www.googleapis.com/auth/calendar.events`  
  View and edit events.

- `https://www.googleapis.com/auth/calendar.events.readonly`  
  View events only.

## Notes

Choose the narrowest scope possible. OAuth consent configuration is required
before publishing the app.
