## Database Import Strategy

1. **Create categories first** with proper UUIDs
2. **Process each markdown file:**
   - Clean Notion metadata (remove frontmatter)
   - Convert relative links to work in app
   - Remove Notion-specific formatting
3. **Insert articles** with:
   - category_id (reference to parent category)
   - title (clean title without hash)
   - content (formatted markdown)
   - search_text (plain text for search)
   - is_published = true
   - tags (extracted from content if applicable)
